KAREN / WINDOWS + ESP32-S3 / S3-N16R8

ഓരോ ഘട്ടമായി
കാരെൻ ഒരുക്കാം.

Windows ലാപ്‌ടോപ്പിനുള്ള മലയാളം നിർദ്ദേശങ്ങൾ. ഈ ഫയൽ Edge അല്ലെങ്കിൽ Chrome-ൽ നേരിട്ട് തുറക്കാം; വായിക്കാൻ Karen server തുടങ്ങേണ്ടതില്ല. Setup downloads-നും live chat-നും ഇന്റർനെറ്റ് വേണം.

ആദ്യം കമ്പ്യൂട്ടറും USB പരിശോധനയും മാത്രം. മൈക്രോഫോൺ, ബട്ടൺ, ആംപ്ലിഫയർ എന്നിവയുടെ wiring മുതിർന്നയാൾ ഒപ്പമുണ്ടാകുമ്പോൾ ചെയ്യുക. ഓരോ command-ഉം ഒന്നൊന്നായി നൽകുക. FAIL അല്ലെങ്കിൽ error കണ്ടാൽ നിർത്തുക.

എല്ലാ PowerShell commands-ഉം app.py ഉള്ള project folder-ൽ നൽകുക. പേജ് മുഴുവൻ PowerShell-ൽ paste ചെയ്യരുത്. ഓരോ command-ന്റെയും കോപ്പി ബട്ടൺ ഉപയോഗിക്കുക.

1

Setup പൂർത്തിയാക്കുക

ഇപ്പോൾ controller ബന്ധിപ്പിക്കേണ്ടതില്ല. Python 3.15 മാറ്റേണ്ടതില്ല. Project folder-ൽ തുറന്ന PowerShell-ൽ ആദ്യം ഇത് നൽകുക:

PowerShell · PyYAML recovery
$env:PYYAML_FORCE_LIBYAML = '0'

അതേ window-ൽ തുടർന്ന് നൽകുക:

PowerShell · setup + example compile
.\bootstrap-windows.cmd --controller esp32_s3 --firmware --compile

ആദ്യ command PyYAML-ന്റെ optional C extension ഒഴിവാക്കും. പുതുക്കിയ bootstrap ഇത് സ്വയം ചെയ്യുന്നു. നിലവിലുള്ള .venv, private settings, saved memory എന്നിവ delete ചെയ്യരുത്.

പരിശോധിക്കുക: “Still working” സാധാരണമാണ്. Downloads-നും compile-നും സമയം വേണം. SETUP COMPLETE കാണുന്നതുവരെ കാത്തിരിക്കുക. ഈ command firmware upload ചെയ്യുന്നില്ല.
2

കമ്പ്യൂട്ടർ പരിശോധിക്കുക

PowerShell · controller disconnected
.\doctor-windows.cmd --controller esp32_s3

Controller ബന്ധിപ്പിച്ചിട്ടില്ലാത്തതിനാൽ port/chip/network സംബന്ധിച്ച WARN വരാം. ഇപ്പോൾ അവ പ്രതീക്ഷിക്കാവുന്നതാണ്.

FAIL കണ്ടാൽ output സൂക്ഷിച്ച് ഇവിടെ നിർത്തുക. WARN വായിച്ച് ഏത് പരിശോധനയാണ് ബാക്കിയെന്ന് മനസ്സിലാക്കുക.
3

ലാപ്‌ടോപ്പിൽ Karen പരിശോധിക്കുക

Project folder-ൽ മറ്റൊരു PowerShell തുറക്കുക. അതാണ് Window A — Server. ആദ്യത്തെ window പിന്നീട് board commands-ന് ഉപയോഗിക്കാം.

Window A · PowerShell
.\start-windows.cmd

ഈ window തുറന്നുതന്നെ വയ്ക്കുക. Chrome/Edge-ൽ http://localhost:8080 തുറക്കുക.

  1. മഴ എങ്ങനെയാണ് ഉണ്ടാകുന്നത്? എന്ന് ചോദിക്കുക. അർത്ഥമുള്ള മലയാളം മറുപടി ലഭിക്കണം.
  2. “Record a question” അമർത്തി laptop microphone permission അനുവദിക്കുക.
  3. അഞ്ച് സെക്കൻഡിനുള്ളിൽ ഒരു ചെറിയ ചോദ്യം ചോദിക്കുക. ശബ്ദത്തിലുള്ള മറുപടി ലഭിക്കുന്നുണ്ടോ എന്ന് നോക്കുക.
API key ഇല്ലെങ്കിൽ മുതിർന്നയാളുടെ സഹായം തേടുക. Key ചാറ്റിലോ screenshot-ലോ അയക്കരുത്. ഒരു spoken apology/error ലഭിക്കുന്നത് വിജയിച്ച test അല്ല.
4

Controller മാത്രം ബന്ധിപ്പിക്കുക

ബോർഡിലെ COM എന്ന് എഴുതിയ USB-C socket ഉപയോഗിക്കുക. USB data cable വേണം. മൈക്രോഫോൺ, ബട്ടൺ, ആംപ്ലിഫയർ, സ്പീക്കർ എന്നിവ ബന്ധിപ്പിക്കരുത്.

ആദ്യത്തെ PowerShell ആണ് Window B — Board. ഇനി board commands ഇതിൽ നൽകുക; അതേ window തുറന്നുവയ്ക്കുക.

Window B · port list
.\.venv\Scripts\python.exe scripts\board.py ports

ഒന്നിലധികം ports ഉണ്ടെങ്കിൽ USB ഊരി list വീണ്ടും പരിശോധിക്കുക. തിരിച്ചുബന്ധിപ്പിക്കുമ്പോൾ വരുന്ന port ആണ് ബോർഡിന്റേത്. COM number ഊഹിക്കരുത്.

Window B · യഥാർഥ COM പേര് നൽകുക
$karenPort = Read-Host "Type the controller's COM port shown above"

ചോദിക്കുമ്പോൾ list-ൽ കണ്ട യഥാർഥ COM പേര് നൽകി Enter അമർത്തുക. തുടർന്ന്:

Window B · chip / flash check
.\doctor-windows.cmd --controller esp32_s3 --port $karenPort --probe-chip
ESP32-S3, 16 MB flash എന്ന് സ്ഥിരീകരിച്ചാൽ മാത്രം തുടരുക. വ്യത്യസ്തമായ ഫലം വന്നാൽ നിർത്തുക. ഈ probe ബോർഡ് reset ചെയ്യാം; flash erase/upload ചെയ്യുന്നില്ല.
5

WiFi വിവരങ്ങൾ നൽകുക

Window A-യിലെ server പ്രവർത്തിച്ചുകൊണ്ടിരിക്കണം. Window B-ൽ:

Window B · laptop IPv4
ipconfig

ഉപയോഗിക്കുന്ന WiFi adapter-ന്റെ IPv4 Address കണ്ടെത്തുക. Default Gateway, VPN/virtual adapter address എന്നിവ എടുക്കരുത്.

Window B · private config തുറക്കുക
notepad firmware\karen_ai\config.h

Notepad-ൽ നിലവിലുള്ള ഈ മൂന്ന് വരികളിലെ example വിവരങ്ങൾ മാറ്റുക. താഴെയുള്ള block PowerShell-ൽ നൽകേണ്ടതല്ല.

config.h · Notepad-ൽ മാത്രം
#define WIFI_SSID "YOUR_2_4_GHZ_HOTSPOT"
#define WIFI_PASSWORD "YOUR_HOTSPOT_PASSWORD"
#define SERVER_ORIGIN "http://192.168.1.50:8080"
  • WiFi-യുടെ യഥാർഥ പേരും password-ഉം നൽകുക. 2.4 GHz WiFi ഉപയോഗിക്കുക.
  • 192.168.1.50 ഒരു example ആണ്. പകരം laptop-ന്റെ യഥാർഥ IPv4 നൽകുക. localhost നൽകരുത്.
  • Quotes, http://, :8080 എന്നിവ നിലനിർത്തുക. അവസാനം slash ചേർക്കരുത്.
  • മറ്റു settings മാറ്റരുത്. Save ചെയ്ത് Notepad അടയ്ക്കുക. Gemini API key ഈ ഫയലിൽ ഇടരുത്.

ലാപ്‌ടോപ്പും ബോർഡും പരസ്പരം ബന്ധപ്പെടാൻ കഴിയുന്ന ഒരേ network-ൽ വേണം. Firewall ചോദിച്ചാൽ മുതിർന്നയാളുടെ സഹായത്തോടെ trusted Private network-ൽ Python അനുവദിക്കുക; firewall മുഴുവനായി ഓഫ് ചെയ്യരുത്.

6

Firmware upload ചെയ്യുക

ബോർഡിൽ ഇപ്പോഴും external വയറുകളൊന്നും ബന്ധിപ്പിക്കരുത്. Monitor തുറന്നിട്ടുണ്ടെങ്കിൽ Ctrl+C ഉപയോഗിച്ച് അടയ്ക്കുക. ഈ upload ബോർഡിലെ നിലവിലുള്ള firmware മാറ്റും.

Window B · compile + upload
.\.venv\Scripts\python.exe scripts\firmware.py --controller esp32_s3 --upload --port $karenPort

ആദ്യം compile നടക്കും. Credentials: private config.h ഒരു വിവരമാണ്; ഒന്നും ടൈപ്പ് ചെയ്യേണ്ടതില്ല. പുതുക്കിയ tool ഓരോ 20 സെക്കൻഡിലും progress കാണിക്കും. Compile limit 10 മിനിറ്റ്; upload limit 4 മിനിറ്റ്. വിശദമായ output അതത് ഘട്ടം അവസാനിക്കുമ്പോൾ കാണിക്കും. Log: .tools/firmware.log.

Upload വിജയിച്ചശേഷം:

Window B · Serial Monitor + log
.\.venv\Scripts\python.exe scripts\board.py monitor --port $karenPort --log

Startup സന്ദേശങ്ങൾ കാണുന്നില്ലെങ്കിൽ RESET/EN ഒരിക്കൽ അമർത്തുക. ഇവ പരിശോധിക്കുക:

Controller: esp32_s3
flash: 16777216 bytes
PSRAM: 8388608 bytes
[WIFI] Connected
[READY]
മുതിർന്നയാൾ തിരികെ വരുന്നതുവരെ ഇവിടെ നിർത്തുക. തെറ്റായ memory size, WiFi error അല്ലെങ്കിൽ ആവർത്തിച്ചുള്ള reboot കണ്ടാൽ output സൂക്ഷിക്കുക. READY മാത്രം കാണുന്നത് എല്ലാ പരിശോധനകളും വിജയിച്ചു എന്നർത്ഥമല്ല. മറ്റൊരു upload/probe നടത്തുന്നതിന് മുമ്പ് monitor Ctrl+C ഉപയോഗിച്ച് അടയ്ക്കണം.
7

മുതിർന്നയാളോടൊപ്പം mic / button wiring

ആദ്യം USB-യും മറ്റു power supplies-ഉം ഊരുക. ബോർഡിൽ എഴുതിയ GPIO നമ്പറുകൾ നോക്കുക; pin സ്ഥാനം എണ്ണരുത്. Microphone VDD-ക്ക് 5V നൽകരുത്. ആംപ്ലിഫയർ ഇപ്പോൾ ബന്ധിപ്പിക്കരുത്.

External button-ന്റെ ഒരു contact GPIO7-ലും മറ്റേത് GND-യിലും ബന്ധിപ്പിക്കുക. അമർത്തുമ്പോൾ മാത്രം ഈ രണ്ട് contacts ബന്ധപ്പെടുന്നുണ്ടെന്ന് മുതിർന്നയാൾ പരിശോധിക്കണം. നാല് കാലുള്ള button-ൽ രണ്ട് contacts ഊഹിച്ച് തിരഞ്ഞെടുക്കരുത്. Onboard BOOT question button ആയി ഉപയോഗിക്കരുത്.

USB തിരിച്ചുബന്ധിപ്പിച്ച് monitor തുറക്കുക. Window A-യിലെ server പ്രവർത്തിക്കണം.

Window B · Serial Monitor
.\.venv\Scripts\python.exe scripts\board.py monitor --port $karenPort --log

Button ഒരിക്കൽ അമർത്തി വിടുക. [MIC] Recording. Speak now. കണ്ടശേഷം അഞ്ച് സെക്കൻഡിനുള്ളിൽ സംസാരിക്കുക. Button ആവർത്തിച്ച് അമർത്താതെ reply പൂർത്തിയാകുന്നതുവരെ കാത്തിരിക്കുക.

പരിശോധിക്കുക: samples=80000/80000, [HTTP] Result: ok എന്നിവ പ്രതീക്ഷിക്കാം. Zero-signal warning അല്ലെങ്കിൽ spoken-error വന്നാൽ test വിജയിച്ചിട്ടില്ല. Laptop-ലെ Karen page refresh ചെയ്ത് തിരിച്ചറിഞ്ഞ ചോദ്യവും മറുപടിയും വായിക്കുക.

ആംപ്ലിഫയർ ബന്ധിപ്പിക്കുന്നതുവരെ ബോർഡിൽ നിന്ന് ശബ്ദം വരില്ല. MAX98357A amplifier, അതിന്റെ power supply, speaker connections എന്നിവ പിന്നീട് മുതിർന്നയാളോടൊപ്പം പരിശോധിക്കാം. Speaker നേരിട്ട് GPIO-യിൽ ബന്ധിപ്പിക്കരുത്.

സഹായം ചോദിക്കുമ്പോൾ: ഘട്ടത്തിന്റെ നമ്പർ, അവസാന error, യഥാർഥ COM port, request ID ഉണ്ടെങ്കിൽ അതും അയക്കുക. API key, WiFi password, .env, config.h എന്നിവ അയക്കരുത്.

Debug logs: .tools/bootstrap.log, .tools/doctor.log, .tools/firmware.log, .tools/serial.log. ഈ പേജ് passwords ചോദിക്കുകയോ വിവരങ്ങൾ അയക്കുകയോ ചെയ്യുന്നില്ല. Checkboxes പേജ് reload ചെയ്യുമ്പോൾ reset ആകും.
