Hosted Karen UI തുറക്കുക

Chrome/Edge-ൽ https://sreehariv.makemykindred.com തുറക്കുക. Browser ചോദിക്കുമ്പോൾ project owner സ്വകാര്യമായി നൽകുന്ന dashboard username/password ഉപയോഗിക്കുക.

ഇനി Windows laptop-ൽ server command പ്രവർത്തിപ്പിക്കേണ്ടതില്ല. AWS server ആണ് AI പ്രവർത്തിപ്പിക്കുന്നത്. UI-യിലെ മലയാളം ഗൈഡുകൾ links വഴി ഈ ഗൈഡും ആദ്യ setup/WiFi ഗൈഡുകളും തുറക്കാം.

Dashboard password, board device token, Gemini API key എന്നിവ വ്യത്യസ്തമാണ്. ഇവ screenshot-ലോ chat-ലോ public repository-യിലോ ഇടരുത്. Hosted UI-യിൽ ഒരേ conversation ആണ് browser-ും board-ും പങ്കിടുന്നത്.

Browser-ൽ text / voice പരീക്ഷിക്കുക

  1. മഴ എങ്ങനെയാണ് ഉണ്ടാകുന്നത്? എന്ന് type ചെയ്ത് അയക്കുക. അർത്ഥമുള്ള മലയാളം മറുപടി ലഭിക്കണം.
  2. Record a question അമർത്തി microphone permission അനുവദിക്കുക. അഞ്ച് സെക്കൻഡിനുള്ളിൽ ചെറിയ ചോദ്യം ചോദിക്കുക.
  3. ശരിയായ ചോദ്യം തിരിച്ചറിഞ്ഞിട്ടുണ്ടോ, പൂർണ്ണമായ ശബ്ദമറുപടി ലഭിക്കുന്നുണ്ടോ എന്ന് പരിശോധിക്കുക.

Microphone-ന് https:// വിലാസം ഉപയോഗിക്കുക. /health-ൽ status ok കാണുന്നത് server എത്തുന്നു എന്നുമാത്രമാണ്; യഥാർഥ AI/voice test വേണം. Apology/provider error വിജയിച്ച മറുപടിയല്ല.

3

Cloud firmware branch എടുക്കുക

Project folder-ൽ PowerShell തുറക്കുക. Serial Monitor തുറന്നിട്ടുണ്ടെങ്കിൽ Ctrl+C നൽകി അടയ്ക്കുക. Owner നൽകിയ codex/aws-cloud-server branch ഉപയോഗിക്കുക. നിലവിലുള്ള config.h/.env അല്ലെങ്കിൽ saved memory delete ചെയ്യരുത്. മാറ്റിയ tracked files ഉണ്ടെന്ന് Git പറയുകയാണെങ്കിൽ force/reset commands ഉപയോഗിക്കാതെ owner-നെ അറിയിക്കുക.

PowerShell · latest branches
git fetch origin
PowerShell · cloud branch
git switch codex/aws-cloud-server
PowerShell · latest cloud changes
git pull --ff-only

ZIP/source copy ആണ് ഉപയോഗിക്കുന്നതെങ്കിൽ owner ഈ branch-ന്റെ updated source നൽകണം; Git commands വേണ്ട. മുൻപ് setup പൂർത്തിയാക്കിയ laptop-ൽ packages വീണ്ടും install ചെയ്യേണ്ടതില്ല.

4

Board-ന് HTTPS address, token, certificate നൽകുക

PowerShell-ൽ താഴെയുള്ള command നൽകി Notepad തുറക്കുക:

PowerShell · private config
notepad firmware\karen_ai\config.h

നിലവിലുള്ള server വരി താഴെപ്പറയുന്നതുപോലെ മാറ്റുക. Device token വരി ഇല്ലെങ്കിൽ ഒരിക്കൽ ചേർക്കുക. ഇത് Notepad-ലുള്ള C++ settings ആണ്; PowerShell-ൽ paste ചെയ്യരുത്.

config.h · owner നൽകിയ യഥാർഥ token ഉപയോഗിക്കുക
#define SERVER_ORIGIN "https://sreehariv.makemykindred.com"
#define KAREN_DEVICE_TOKEN "PASTE_PRIVATE_DEVICE_TOKEN_FROM_OWNER"

Owner device token സ്വകാര്യമായി നൽകും. ഉദാഹരണ token അതേപടി upload ചെയ്യരുത്. നിലവിലെ WIFI_SSID / WIFI_PASSWORD board ഉപയോഗിക്കുന്ന 2.4 GHz network-നുള്ളതായിരിക്കണം.

Trusted root CA bundle download ചെയ്യുക. അത് Notepad-ൽ തുറന്ന്, മുഴുവൻ BEGIN CERTIFICATE / END CERTIFICATE blocks-ഉം config.h-യിലെ നിലവിലുള്ള ROOT_CA block-ന്റെ R"PEM(-നും )PEM";-നും ഇടയിൽ paste ചെയ്യുക. Block-ന്റെ പുറത്തുള്ള C++ വരികൾ നീക്കരുത്. Certificate public ആണ്; private key/token ഇതിൽ ചേർക്കരുത്.

TLS certificate verification off ചെയ്യരുത്. HTTPS-ന് board clock ശരിയാക്കാൻ NTP/internet ലഭിക്കണം. Root certificate വേണ്ടെന്ന് പറയുന്ന workaround ഉപയോഗിക്കരുത്.

മറ്റ് pin/audio settings മാറ്റാതെ Ctrl+S നൽകി save ചെയ്ത് Notepad അടയ്ക്കുക. File config.h തന്നെയായിരിക്കണം.

5

USB വഴി upload ചെയ്ത് monitor പരിശോധിക്കുക

COM USB socket-ൽ data cable ബന്ധിപ്പിക്കുക. PowerShell-ൽ ഇപ്പോഴത്തെ port കണ്ടെത്തുക:

PowerShell · actual COM port
.\.venv\Scripts\python.exe scripts\board.py ports
PowerShell · list-ൽ കണ്ട COM പേര് നൽകുക
$karenPort = Read-Host "Type the controller COM port shown above"

ചോദിക്കുമ്പോൾ list-ൽ കണ്ട യഥാർഥ COM പേര് നൽകി Enter അമർത്തുക. ഇതേ window-ൽ upload ചെയ്യുക; Serial Monitor അടച്ചിരിക്കണം:

PowerShell · ESP32-S3 compile + upload
.\.venv\Scripts\python.exe scripts\firmware.py --controller esp32_s3 --upload --port $karenPort --verbose

Error ഇല്ലാതെ upload അവസാനിച്ചശേഷം:

PowerShell · Serial Monitor
.\.venv\Scripts\python.exe scripts\board.py monitor --port $karenPort --log

Startup കാണുന്നില്ലെങ്കിൽ RESET/EN ഒരിക്കൽ അമർത്തുക. Controller: esp32_s3, flash 16777216, PSRAM 8388608, [WIFI] Connected, [READY] എന്നിവ പരിശോധിക്കുക. READY മാത്രം വിജയം തെളിയിക്കുന്നില്ല.

6

Board-ൽ നിന്ന് cloud reply ഉറപ്പാക്കുക

  1. Microphone/external question button മുമ്പ് പരിശോധിച്ച് ബന്ധിപ്പിച്ചിരിക്കണം. External button ഒരിക്കൽ അമർത്തി വിടുക.
  2. [MIC] Recording. Speak now. കണ്ടശേഷം അഞ്ച് സെക്കൻഡിനുള്ളിൽ ചെറിയ ചോദ്യം ചോദിക്കുക.
  3. Reply പൂർത്തിയാകുന്നതുവരെ വീണ്ടും അമർത്തരുത്. samples=80000/80000, [HTTP] Result: ok എന്നിവ പ്രതീക്ഷിക്കാം.
  4. Hosted UI refresh ചെയ്ത് തിരിച്ചറിഞ്ഞ ചോദ്യവും മറുപടിയും വായിക്കുക. Speaker ബന്ധിപ്പിച്ചിട്ടുണ്ടെങ്കിൽ പൂർണ്ണമായ ശബ്ദമറുപടി കേൾക്കണം.
401/403: ശരിയായ device token-ും പുതിയ firmware-ും പരിശോധിക്കുക. TLS/clock error: HTTPS വിലാസം, root CA, NTP/internet പരിശോധിക്കുക. spoken-error: owner AWS server logs പരിശോധിക്കണം. Speaker ഇല്ലെങ്കിൽ audible test ബാക്കിയാണ്.

ഇനി laptop sleep/off ആണെങ്കിലും board പ്രവർത്തിക്കാം; board-ന് power, WiFi internet, പ്രവർത്തിക്കുന്ന AWS server എന്നിവ വേണം. പുതിയ WiFi-യിലേക്ക് മാറുമ്പോൾ WiFi പേര്/password മാത്രം മാറ്റി upload ചെയ്യുക; ഈ HTTPS server address നിലനിർത്തുക.

ഇത് ഒരാഴ്ചത്തെ AWS test ആണ്. നിശ്ചയിച്ച cleanup സമയത്ത് server-ും ഈ address-ന്റെ DNS record-ും നീക്കും. അതിനുശേഷം hosted UI/board cloud reply ലഭിക്കില്ല. Permanent memory ആവശ്യമായാൽ owner cleanup-ന് മുമ്പ് backup എടുക്കണം.

സഹായത്തിന്: അവസാന error, ഘട്ടം, actual COM port, request ID എന്നിവ നൽകുക. Password/token/API key അല്ലെങ്കിൽ config.h അയക്കരുത്.
